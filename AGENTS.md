# Instructions for agents

This project's rules live in **[`CLAUDE.md`](./CLAUDE.md)**. Read it before working.

This file exists only so agents that look for `AGENTS.md` by convention (Codex, Cursor,
Gemini CLI, and others) find their way. **Do not duplicate the content here** — two copies
diverge and then nobody knows which one rules.

Authoritative documents, in order: `BRIEF.md` → `PRODUCT.md` → `DESIGN.md`.
(`CONTENT.md` does not exist — this is a greenfield project with no site to inventory.)

`PRODUCT.md` is authoritative as of 2026-09-05. `DESIGN.md` is still a stub, so **do not
start writing UI.** The next step is the `/impeccable` new-work flow, which writes it — this
project has a new visual identity, so `/impeccable document` does not apply.
